Reliability

The firm claims —+ companies; its site names — (—%), and every portfolio figure uses the named ones. Published portfolio counts range from — to —. SEC matches and stage labels were AI-drafted and spot-checked (—% of — stages correct), so stages are approximate. First-listed year is not investment year. Alumni is not exited: — current companies also list an alumni founder.

Method

  • Code and data: GitHub repository (scripts, source CSVs and the JSON files this page reads).
  • Roster, lists and sectors: precursorvc.com, 19 November 2026.
  • Alumni outcomes: website check, then press search. Confidence: high = press, medium = redirect or one source, low = website only.
  • Fund sizes: SEC Form D, except Fund V's April 2025 close (VCWire). Rounds: roster matched to SEC Form D (2015 to 2026); AI approved matches on name, location and founding year; stages by rule.
  • First-listed year: Wayback Machine; copies naming under five companies ignored.
  • — companies appear only in the founders view (counted).
